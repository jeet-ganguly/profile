# Windows Threat Hunting — Important Event IDs & Sysmon

> Windows generates security telemetry through **Windows Security Logs, System Logs, PowerShell logs, and Sysmon**. Threat hunters use Event IDs to identify authentication activity, process execution, persistence, privilege changes, lateral movement, network activity, and defense evasion.
>
> An Event ID should not normally be treated as an alert by itself. The real value comes from **correlating multiple events with the user, process, command line, source IP, destination, and timeline**.

These notes cover:

- Important Windows Security Event IDs
- Important Account and Authentication Events
- Important Process and Object Access Events

- Important Kerberos Events

# 1. Windows Event IDs

An **Event ID** identifies a particular type of event generated by Windows or an application.

For example:

```text
4624

↓

Successful Logon
```

```text
4688

↓

Process Creation
```

```text
1102

↓

Security Log Cleared
```

Event IDs are commonly found in:

```text
Security

System

Application

PowerShell

Sysmon
```

# 2. Authentication and Logon Events

These events are important for detecting:

```text
Brute Force

Password Spraying

Compromised Accounts

Lateral Movement

Unusual Logons
```

| Event ID | Event | Explanation | Hunting Use |
|---|---|---|---|
| **4624** | Successful Logon | An account successfully logged on to the system. | Look for unusual users, source IPs, logon types, and unusual times. |
| **4625** | Failed Logon | An account failed to log on. | Multiple failures may indicate brute force or password spraying. |
| **4634** | Logoff | A logon session was terminated. | Helps build authentication timelines. |
| **4647** | User Initiated Logoff | A user initiated the logoff operation. | Useful for correlating user sessions. |
| **4648** | Explicit Credentials Used | A logon was attempted using explicitly supplied credentials. | Useful for investigating credential abuse and lateral movement. |
| **4672** | Special Privileges Assigned | Special privileges were assigned to a new logon. | Important when associated with highly privileged accounts. |
| **4740** | Account Locked Out | An account was locked because of failed authentication attempts. | Useful for detecting password attacks. |

## Logon Types

Event ID `4624` contains a **Logon Type**.

Common types:

| Logon Type | Meaning |
|---:|---|
| 2 | Interactive |
| 3 | Network |
| 4 | Batch |
| 5 | Service |
| 7 | Unlock |
| 8 | NetworkCleartext |
| 9 | NewCredentials |
| 10 | RemoteInteractive / RDP |
| 11 | CachedInteractive |

For threat hunting, unusual combinations are important.

Example:

```text
4624

+

Logon Type 10

+

Unexpected Source IP

↓

Possible Suspicious RDP Logon
```

# 3. Process and Privilege Events

These events help investigate process execution and privilege-related activity.

| Event ID | Event | Explanation | Hunting Use |
|---|---|---|---|
| **4688** | Process Created | A new process was created. | One of the most important events for process-based threat hunting. |
| **4689** | Process Terminated | A process terminated. | Helps complete process timelines. |
| **4672** | Special Privileges Assigned | A logon received special privileges. | Useful for identifying privileged sessions. |
| **4673** | Sensitive Privilege Use | A privileged service was called. | Can help investigate suspicious privilege use. |
| **4674** | Operation Attempted on Privileged Object | An operation was attempted on a privileged object. | Useful for investigating privileged activity. |

## Event ID 4688

```text
Process Created

↓

Process Name

+

Command Line

+

Parent Process

+

User

↓

Threat Hunting
```

Example:

```text
explorer.exe

↓

powershell.exe

↓

Suspicious Command
```

The process relationship can provide much more information than the Event ID alone.

# 4. Account Management Events

Account management events help identify changes to users and groups.

| Event ID | Event | Explanation | Hunting Use |
|---|---|---|---|
| **4720** | User Account Created | A new user account was created. | Look for unauthorized accounts. |
| **4722** | User Account Enabled | A user account was enabled. | Investigate unexpected account activation. |
| **4723** | Password Change Attempt | A user attempted to change their own password. | Useful in account investigations. |
| **4724** | Password Reset Attempt | An attempt was made to reset another user's password. | Important for privileged account investigations. |
| **4725** | User Account Disabled | A user account was disabled. | Investigate unexpected account changes. |
| **4726** | User Account Deleted | A user account was deleted. | Useful for detecting account cleanup or unauthorized changes. |
| **4732** | Member Added to Local Security Group | A member was added to a local security-enabled group. | Important when the group is Administrators. |
| **4733** | Member Removed from Local Security Group | A member was removed from a local security-enabled group. | Useful for tracking group changes. |
| **4738** | User Account Changed | A user account was modified. | Investigate unexpected account changes. |
| **4740** | Account Locked Out | An account was locked out. | Useful for detecting password attacks. |
| **4798** | Local Group Membership Enumerated | A user's local group memberships were enumerated. | Can provide context for account discovery. |
| **4799** | Security-Enabled Local Group Membership Enumerated | A security-enabled local group was queried. | Useful when investigating enumeration activity. |

## Important Group Events

For domain groups:

```text
4727 → Security-enabled Global Group Created

4728 → Member Added to Security-enabled Global Group

4729 → Member Removed from Security-enabled Global Group

4730 → Security-enabled Global Group Deleted
```

For local groups:

```text
4731 → Security-enabled Local Group Created

4732 → Member Added

4733 → Member Removed

4734 → Security-enabled Local Group Deleted
```

# 5. Kerberos and Credential Events

Kerberos events are particularly important in **Active Directory threat hunting**.

| Event ID | Event | Explanation | Hunting Use |
|---|---|---|---|
| **4768** | Kerberos TGT Requested | A Kerberos Ticket Granting Ticket was requested. | Useful for authentication analysis and unusual TGT requests. |
| **4769** | Kerberos Service Ticket Requested | A Kerberos service ticket was requested. | Important for service access and Kerberoasting investigations. |
| **4771** | Kerberos Pre-Authentication Failed | Kerberos pre-authentication failed. | Repeated failures may indicate password attacks. |
| **4776** | Credential Validation | A domain controller attempted to validate credentials. | Useful for NTLM credential activity and authentication investigations. |
| **4767** | User Account Unlocked | A previously locked account was unlocked. | Useful for tracking account recovery and suspicious changes. |

## Kerberos Flow

```text
User

↓

4768

↓

TGT Requested

↓

4769

↓

Service Ticket Requested

↓

Service Access
```

A suspicious sequence can be investigated by correlating:

```text
4768

+

4769

+

4624

↓

Authentication Timeline
```

These events are useful for investigating file access, SMB activity, and lateral movement.

| Event ID | Event | Explanation | Hunting Use |
|---|---|---|---|
| **4656** | Handle to an Object Requested | A handle to an object was requested. | Useful when auditing specific object access. |
| **4663** | Object Accessed | An operation was performed on an object. | Useful for investigating access to files, folders, and other objects. |
| **4670** | Permissions Changed | Permissions on an object were changed. | Important for detecting unauthorized permission changes. |
| **5140** | Network Share Accessed | A network share was accessed. | Useful for SMB and lateral movement investigations. |
| **5145** | Network Share Object Checked | Detailed information about access to an object through a network share. | Useful for investigating file/share access. |

## Example

```text
4624

↓

Network Logon

↓

5140

↓

SMB Share Access

↓

5145

↓

Specific Share Object Access
```

This can help build a lateral movement timeline.

# 7. Security Policy and Defense Evasion Events

These events can help identify attempts to modify security controls or remove evidence.

| Event ID | Event | Explanation | Hunting Use |
|---|---|---|---|
| **1102** | Security Audit Log Cleared | The Security event log was cleared. | Important defense-evasion indicator. |
| **4719** | System Audit Policy Changed | The system audit policy was changed. | Investigate unexpected security logging changes. |
| **4907** | Auditing Settings on Object Changed | Auditing settings for an object were modified. | Useful for detecting changes that may reduce visibility. |
| **4904** | Security Event Source Registered | A security event source was registered. | Useful for investigating changes to event sources. |
| **4906** | CrashOnAuditFail Value Changed | The system audit-failure behavior was changed. | Useful for investigating audit configuration changes. |

## Event ID 1102

```text
Security Log

↓

Cleared

↓

Event ID 1102
```

Possible explanations include:

```text
Administrator Maintenance

+

Potential Defense Evasion
```

Therefore:

```text
1102

≠

Automatically Malicious
```

Always investigate:

```text
Who?

When?

From Where?

What Happened Before?

What Happened After?
```

# 10. Important Sysmon Event IDs

**Sysmon (System Monitor)** provides detailed telemetry about system activity.

Sysmon events are commonly found under:

```text
Applications and Services Logs

↓

Microsoft

↓

Windows

↓

Sysmon

↓

Operational
```

Sysmon events are observational telemetry; they become useful for threat hunting when correlated with other events and context.

## Process and Execution Events

| Event ID | Event | Explanation | Hunting Use |
|---:|---|---|---|
| **1** | Process Create | Records detailed information about a newly created process, including command line, parent process, hashes, and Process GUID. | Process execution and parent-child hunting. |
| **5** | Process Terminate | Records when a process terminates. | Build complete process timelines. |
| **8** | CreateRemoteThread | Records remote thread creation in another process. | Investigate process injection. |
| **10** | Process Access | Records one process opening another process. | Investigate credential theft, memory access, and injection. |
| **25** | Process Tampering | Records detected process image manipulation. | Investigate process hollowing and related tampering. |

## Network Events

| Event ID | Event | Explanation | Hunting Use |
|---:|---|---|---|
| **3** | Network Connection | Records network connections associated with processes. | Investigate C2, unusual destinations, and suspicious processes. |
| **22** | DNS Query | Records DNS queries made by processes. | Investigate suspicious domains, beaconing, and C2 infrastructure. |

## File Events

| Event ID | Event | Explanation | Hunting Use |
|---:|---|---|---|
| **2** | File Creation Time Changed | Records when a process explicitly changes a file's creation timestamp. | Investigate timestamp manipulation. |
| **11** | File Create | Records when a file is created or overwritten. | Detect dropped payloads and suspicious files. |
| **15** | FileCreateStreamHash | Records creation of a named file stream and its hash. | Useful for Alternate Data Stream investigation. |
| **23** | File Delete | Records file deletion and archives the deleted file when configured for Event ID 23. | Investigate cleanup, malware activity, and ransomware. |
| **26** | File Delete Logged | Records file deletion without the archive behavior of Event ID 23. | Investigate file cleanup and deletion activity. |

## Image and Driver Events

| Event ID | Event | Explanation | Hunting Use |
|---:|---|---|---|
| **6** | Driver Load | Records when a driver is loaded. | Investigate suspicious or unexpected kernel-level activity. |
| **7** | Image Load | Records when a DLL or executable image is loaded into a process. | Investigate DLL side-loading and suspicious module loading. |

## Registry Events

| Event ID | Event | Explanation | Hunting Use |
|---:|---|---|---|
| **12** | Registry Object Create/Delete | Records registry key or value creation/deletion. | Investigate persistence and configuration changes. |
| **13** | Registry Value Set | Records a registry value being modified. | Important for registry-based persistence. |
| **14** | Registry Object Rename | Records registry key/value renaming. | Investigate registry manipulation. |

## Named Pipe and WMI Events

| Event ID | Event | Explanation | Hunting Use |
|---:|---|---|---|
| **17** | Pipe Created | Records named pipe creation. | Investigate IPC and malware activity. |
| **18** | Pipe Connected | Records named pipe connections. | Investigate suspicious inter-process communication. |
| **19** | WMI Event Filter | Records WMI event filter creation. | Investigate WMI persistence. |
| **20** | WMI Event Consumer | Records WMI event consumer creation. | Investigate WMI-based persistence. |
| **21** | WMI Binding | Records WMI filter-to-consumer binding. | Important for complete WMI persistence investigation. |

## Sysmon Service and Configuration Events

| Event ID | Event | Explanation | Hunting Use |
|---:|---|---|---|
| **4** | Sysmon Service State Changed | Indicates that the Sysmon service changed state. | Investigate unexpected Sysmon stopping. |
| **16** | Sysmon Configuration Changed | Indicates that the Sysmon configuration was changed. | Investigate telemetry configuration changes. |
| **255** | Sysmon Error | Indicates an internal Sysmon error. | Check whether telemetry is functioning correctly. |

## Other Useful Sysmon Events

| Event ID | Event | Explanation | Hunting Use |
|---:|---|---|---|
| **9** | RawAccessRead | Records direct raw access to disks. | Investigate unusual low-level disk access. |
| **24** | Clipboard Change | Records clipboard content changes. | Investigate suspicious clipboard collection. |
| **27** | Executable File Detected | Records detection of an executable file based on Sysmon configuration. | Investigate executable staging. |
| **28** | Executable File Blocked | Records an executable file being blocked. | Investigate defensive enforcement and suspicious execution. |
| **29** | Executable File Deleted | Records deletion of an executable file after detection/blocking scenarios. | Investigate malware cleanup and staging. |

## Biggest Concept

```text
Event ID

↓

Context

↓

Correlation

↓

Timeline

↓

Behavior

↓

Detection
```

The goal of threat hunting is not simply to find an Event ID.

```text
Find Event

↓

Understand Context

↓

Correlate Related Events

↓

Build Attack Timeline

↓

Identify Suspicious Behavior
```

The most important skill is:

```text
Understand the Event

+

Understand the Context

+

Correlate Related Events

=

Understand the Attack
```
